# Pulse

A modern adult rhythm game.

Match the beat. Fill the meter. Don't break the mood.

## Play

Open the deployed site or open `index.html` locally.

## Controls

- Keys **1 / 2 / 3** — hit in time
- Key **5** — special
- 3 hearts
- Fill the meter to finish each scene

## Deploy

Connected to Vercel via GitHub. Push to `main` to redeploy.
